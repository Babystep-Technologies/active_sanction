Choose your lists, screen a name, and read the score:

{/* sample: illustrative -- reaches two government endpoints and needs a configured store */}

```ruby
# Every list, or only the ones your obligations actually cover.
ActiveSanction.sync!(:ofac_sdn, :un_consolidated)

hit = ActiveSanction.screen(
  name:    "Bosco Ntaganda",
  type:    :individual,
  sources: %i[ofac_sdn un_consolidated]
).first

hit.score        # => 100.0
hit.source       # => :un_consolidated -- which list answered
hit.snapshot_id  # => "sha256:4e39b663..." -- the exact version of it
```

<div class="screening-aid" id="screening-aid">
  <strong>This library is a screening aid. It is not legal advice, and it is
  not a compliance program.</strong> Verify every hit against the official
  published list before acting on it. A clean result means <em>nothing over the
  threshold in the lists we currently hold</em> — it does not mean <em>not
  sanctioned</em>.
</div>

The gem is complete on its own — every supported list is fetchable, parseable
and screenable locally, forever, with no account and no key.

---

Screening compares folded strings, never published ones. This is the one
thing you can try with no data at all:

{/* sample: runnable */}

```ruby
require "active_sanction"

ActiveSanction::Normalizer.call("O'Brien, Seán").value
# => "o brien sean"
```
