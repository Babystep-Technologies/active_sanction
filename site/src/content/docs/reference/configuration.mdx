Every setting `ActiveSanction.configure` and `Client.new` accept. Type and
default come from `Configuration` itself — see
[`site/bin/generate_configuration.rb`](https://github.com/Babystep-Technologies/active_sanction/blob/main/site/bin/generate_configuration.rb) —
so a setting added or retyped here needs no edit to this page. The one line of
effect for each is written by hand below the table. Full method signatures are
in the [generated API documentation](/active_sanction/api/ActiveSanction/Configuration.html).

An unknown setting, or a value a writer refuses, raises `ConfigurationError`
at the point it is set. See the [error hierarchy](/active_sanction/reference/errors/).

## Two settings that travel with every result

`scorer_weights` and `normalizer_dictionary` are not simple values — they are
objects with their own defaults, described in full on
[How matching works](/active_sanction/explanation/how-matching-works/) rather
than restated here. `scorer_weights` is stamped onto every `MatchResult`, so a
tuned installation's decisions stay explainable after the defaults move.

## `screening_threshold` and `candidate_limit`

The two settings a host most often tunes.

- **`screening_threshold`** trades recall for precision. See
  [the accuracy report](/active_sanction/reference/accuracy/) for what moving
  it away from the default costs, measured rather than guessed.
- **`candidate_limit`** trades recall for latency: it bounds how many names the
  index hands the scorer before a threshold is applied. See
  [performance characteristics](/active_sanction/reference/performance/).

## Reading and changing configuration

{/* sample: runnable */}

```ruby
ActiveSanction.configure do |c|
  c.user_agent = "my-app/1.0 (compliance@example.com)"
  c.screening_threshold = 80
end

ActiveSanction.config.screening_threshold   # => 80.0
```

`Client.new` accepts every setting above as a keyword argument, for a process
holding more than one configuration at once:

{/* sample: illustrative -- needs a synced OFAC snapshot to be a useful client */}

```ruby
audit_client = ActiveSanction::Client.new(sources: %i[ofac_sdn], screening_threshold: 60)
```

`Configuration#with` derives a copy from an existing, frozen configuration
with some settings changed:

{/* sample: illustrative -- config here is a placeholder for a held Configuration */}

```ruby
audit = config.with(storage: pinned_store, sources: %i[ofac_sdn])
```
