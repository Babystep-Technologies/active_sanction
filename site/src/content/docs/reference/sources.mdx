The seven lists this gem reads today, in the order the README lists them.
Every field below comes from what the adapter declares and what
[the canary](https://github.com/Babystep-Technologies/active_sanction#the-upstream-canary)
last measured into `.github/baselines` — nothing here is typed by hand, and
the [full account of what each parser does and does not get right](https://github.com/Babystep-Technologies/active_sanction#known-data-limitations-per-source)
lives in the README, condensed to one paragraph per source below.

## What is not covered

- No politically-exposed-person data, no adverse media, no beneficial
  ownership, no OFAC 50 Percent Rule resolution — a subsidiary that is
  sanctioned only by virtue of its owners is not on any of these files.
- Seven lists ship: two US, one UN, one Canada, one EU, one UK, one Australia.
  A jurisdiction outside that set is not covered.
- Non-Latin script is not transliterated. A Cyrillic name matches a Cyrillic
  query and nothing else.
